### Modesto

**An AI-native development workspace for coding agents, repositories, research, review, and remote sessions.**

![Status](https://img.shields.io/badge/status-active%20development-7c3aed?style=flat-square)
![macOS](https://img.shields.io/badge/macOS-111111?style=flat-square&logo=apple&logoColor=white)
![iOS](https://img.shields.io/badge/iOS-111111?style=flat-square&logo=apple&logoColor=white)
![Developer Tools](https://img.shields.io/badge/developer%20tools-27272a?style=flat-square)

```text
modesto/
├── code        multi-provider AI development workspace
├── mobile      remote companion for active coding sessions
├── review      repository-aware AI code review
├── research    source-grounded technical research
└── cowork      shared agent workflows for teams
```

**Core ideas**

- Work across Codex, Claude, Gemini, Cursor, and local models
- Give agents repository context before execution
- Keep developers in control of changes and handoffs
- Connect desktop and mobile sessions
- Bring research and review into one workspace

`Swift` `TypeScript` `Python` `React` `Tauri` `LLM APIs`

### CommuteNEXT

**A native real-time transit experience built around live operations, useful alerts, and clean product design.**

![Status](https://img.shields.io/badge/status-shipping-0284c7?style=flat-square)
![iPhone](https://img.shields.io/badge/iPhone-111111?style=flat-square&logo=apple&logoColor=white)
![Transit](https://img.shields.io/badge/real--time%20transit-075985?style=flat-square)

```text
commutenext/
├── live        vehicle positions and service status
├── alerts      useful operational updates
├── saved       trips, trains, and routes
├── widgets     glanceable commute information
└── 2.0         redesigned native transit experience
```

**Core ideas**

- GTFS and GTFS-Realtime integration
- Live vehicle locations and service alerts
- Native mapping and route intelligence
- Widgets and Live Activities
- Independently designed, engineered, and shipped

`SwiftUI` `MapKit` `GTFS-RT` `Core Location` `ActivityKit`
