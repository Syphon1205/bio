## About

I am a product-focused software engineer working across AI systems, developer tooling, and native Apple platforms. I like taking ambitious ideas from an early concept to working software, with a focus on clean interfaces, practical architecture, and products people can actually use.

My current work is centered on **Modesto**, an AI-native development platform, and **CommuteNEXT**, a native real-time transit application.

## What I am building

### Modesto

An AI-native development workspace designed to connect multiple coding agents and runtimes through one product.

- Multi-provider support for Codex, Claude, Gemini, Cursor, and local models
- Repository context, research, tool execution, and agent handoffs
- Integrated code review and developer-controlled change workflows
- Native desktop experience with an iOS companion for remote sessions

### CommuteNEXT

A native SwiftUI transit application built around live operational data and a cleaner commuter experience.

- GTFS and GTFS-Realtime integration
- Live vehicle locations, service alerts, maps, and saved trips
- Widgets and Live Activities
- Designed, engineered, and shipped independently to the App Store
